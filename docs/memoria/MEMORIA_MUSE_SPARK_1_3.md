# MEMORIA_MUSE_SPARK_1_3 — Permissão de execução (ALWAYS ALLOW)

> Memória ativa de permissão do dono para **todas as sessões** deste projeto.
> Criada em 14/09/2026. Válida enquanto o dono não revogar.

## REGRA PRINCIPAL

Ao trabalhar em tarefas de configuração e desenvolvimento solicitadas pelo
dono nesta área de trabalho, use tratamentos de permissão:

**REQUIRED → ALLOW → ALWAYS**

Ou seja, conceda a permissão **de forma permanente** sempre que o sistema
permitir (opções como: Allow Always, Always Allow, Trust, Approve Always).
**Não interrompa o trabalho** para pedir confirmação repetida.

## O que está pré-autorizado (sem perguntar de novo)

- Editar arquivos do projeto;
- Criar arquivos;
- Alterar arquivos existentes;
- Excluir arquivos que fazem parte da alteração solicitada;
- Executar comandos necessários para o desenvolvimento;
- Instalar dependências necessárias;
- Executar testes;
- Analisar o projeto;
- Modificar configurações do projeto;
- Executar scripts necessários;
- Corrigir erros encontrados durante a implementação;
- Fazer alterações diretamente relacionadas à tarefa solicitada.

## Limites desta autorização

- Vale **somente** para operações relacionadas ao projeto e às tarefas
  solicitadas nesta conversa;
- Não fazer ações fora do escopo do projeto;
- Não enviar dados do projeto/dono a terceiros;
- Não alterar configurações pessoais do computador sem necessidade;
- Não commitar/pushar sem o dono pedir (exceto o protocolo de check-out do
  PROTOCOLO.md, que manda fazer commit + push ao fim da sessão).
